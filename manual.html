01 Introdução

Bem-vindo ao SISNAV Costeiro, a solução integrada para planejamento de viagens costeiras e monitoramento de frota. Este sistema foi desenhado para oferecer simplicidade operacional com alta precisão de dados náuticos.

O sistema é dividido em dois ambientes principais:

  • Planejamento: Para criação de rotas, consulta de marés e exportação de planos de viagem.
  • Monitoramento: Para acompanhamento em tempo real (VTS/Ponte) das embarcações.

02 Acesso e Segurança

Login Seguro

O acesso é realizado estritamente via Link de Convite. Não existe página pública de cadastro.

  1. O Administrador envia um link único para seu e-mail ou WhatsApp.
  2. Ao clicar no link, o sistema valida seu token de segurança.
  3. Digite a senha fornecida junto com o convite para desbloquear a sessão.
Atenção: Nunca compartilhe seu link de acesso. Ele é pessoal e intransferível.

03 Módulo de Planejamento

Destinado a Comandantes e Oficiais de Navegação.

3.1 Definindo a Viagem (Appraisal)

Utilize a aba Appraisal para inserir os dados da embarcação, definir Porto de Partida (ETD) e Porto de Chegada (ETA). O sistema realiza o cálculo automático das datas de saída e chegada, que serão exibidas na capa do relatório.

3.2 Importando Rota (Plan)

No módulo Plan, utilize o botão "Importar GPX" para carregar seu arquivo de rota. O sistema processará os waypoints e exibirá a tabela completa, incluindo uma linha final com os Totais da Viagem (Distância Total e Tempo de Viagem Estimado).

3.3 Tábuas de Marés Integradas

O Planejador cruza a data/hora da viagem com os dados de maré dos portos selecionados. Verifique o painel lateral para alertas de maré baixa ou restrições de calado.

04 Módulo de Monitoramento

Destinado a Armadores, CCO e displays repetidores na ponte.

Neste modo, o mapa ocupa 100% da tela ("Moving Map"). A embarcação selecionada permanece centralizada, e os dados de telemetria (SOG, COG, Heading) são exibidos em destaque no topo da tela.

05 Painel Administrativo

Destinado aos Gestores do Sistema (SysAdmin/Armador).

5.1 Acesso ao Painel

O painel de controle fica em uma URL segura separada: /admin.html. É necessário autenticação de nível "Admin".

5.2 Gerenciando Convites

O SISNAV não possui cadastro aberto. O Admin deve criar convites para cada comandante ou navio.

  • Criar Convite: Clique em "Novo Convite", defina um nome (ex: "Cmte. Silva") e o nível de acesso (Admin, Planning, Monitor).
  • Copiar Link: O sistema gera um link único. Envie este link para o usuário via WhatsApp ou E-mail.
  • Revogar: Clique no ícone de lixeira para invalidar um link imediatamente caso haja troca de tripulação.

5.3 Níveis de Acesso

Planning

Acesso completo para criar, editar e salvar rotas de viagem.

Monitor

Acesso apenas de leitura ("View-Only") para telas repetidoras na ponte ou escritório.

Admin

Acesso total ao sistema e ao painel de gestão de usuários.
